# 上位机 PDO 协议说明（EtherCAT，双向 256 B）

日期：2026-11-25。面向主站（Linux + SOEM）实现，对应从站代码：`project/thread/ecat/pdo_layout.hpp`、`trd_ecat.cpp`。

## 1. 总览

| 项 | 值 |
| --- | --- |
| 传输 | EtherCAT 周期 PDO |
| 周期 | 1 ms |
| RxPDO（主站 → 从站） | 256 B |
| TxPDO（从站 → 主站） | 256 B |
| 字节序 | 小端（x86 与 RISC-V 均为 LE） |
| 对齐 | 全部 `packed`，无填充；按偏移逐字节布局 |
| 浮点 | IEEE-754 binary32 |
| 版本 | `proto_major=1`，`proto_minor=0` |

本版**不含电机**：电机反馈区、电机命令区、DeviceOperation 均为预留区，从站写零/忽略，主站也必须写零。

## 2. TxPDO：从站 → 主站（256 B）

| 偏移 | 内容 | 字节 |
| ---: | --- | ---: |
| 0 | FeedbackHeader | 40 |
| 40 | RemoteFeedback | 32 |
| 72 | ImuFeedback | 56 |
| 128 | 电机反馈区（预留，全零） | 128 |

### 2.1 FeedbackHeader（偏移 0，40 B）

| 偏移 | 字段 | 类型 | 语义 |
| ---: | --- | --- | --- |
| 0 | magic | u32 | 固定 `0x31424450`（ASCII "PDB1"，按小端读为字节 `50 44 42 31`） |
| 4 | proto_major | u16 | 1 |
| 6 | proto_minor | u16 | 0 |
| 8 | mcu_boot_id | u32 | 每次上电重新生成；主站据此判断从站是否重启 |
| 12 | feedback_seq | u32 | 每 1 ms 自增，溢出回绕 |
| 16 | mcu_tick_us | u32 | 本帧组帧时刻，MCU 本地 µs |
| 20 | applied_command_seq | u32 | 本版恒 0（无执行器） |
| 24 | accepted_host_session | u16 | 当前被接纳的主机会话号；0 = 无有效会话 |
| 26 | operation_ack_seq | u16 | 本版恒 0 |
| 28 | status_flags | u16 | bit0：已接纳会话（`accepted_host_session != 0`）；其余保留为 0 |
| 30 | fault_code | u16 | 本版恒 0 |
| 32 | armed_mask | u8 | 本版恒 0 |
| 33 | can_health | u8 | 本版恒 0 |
| 34 | reserved | u8[6] | 全零 |

**判断从站重启**：`mcu_boot_id` 与上一帧不同 → 从站重启，主站必须重新取 boot_id、重新建立会话。

### 2.2 RemoteFeedback（偏移 40，32 B）

| 偏移 | 字段 | 类型 | 语义 |
| ---: | --- | --- | --- |
| 40 | source_seq | u32 | 遥控消息帧序号，来自从站内部 `version`；每解析一帧自增 |
| 44 | sample_tick_us | u32 | 该帧的**采样时刻**（MCU 本地 µs），不是 PDO 组帧时刻 |
| 48 | axis[0] | f32 | chassisx，归一化 [-1, 1] |
| 52 | axis[1] | f32 | chassisy，归一化 [-1, 1] |
| 56 | axis[2] | f32 | yaw，归一化 [-1, 1] |
| 60 | axis[3] | f32 | pitch，归一化 [-1, 1] |
| 64 | controls | u16 | 开关位，见下表 |
| 66 | protocol | u8 | 0 = 未报告；本版恒 0 |
| 67 | status | u8 | bit0：已收到过有效遥控帧；bit1 保留（失联请用 sample_tick_us 的 age 判断） |
| 68 | reserved | u8[4] | 全零 |

`controls` 位定义（1 = On / Spin）：

| 位 | 含义 |
| ---: | --- |
| 0 | robot_ctrl 整车总开关 |
| 1 | chassis_mode = Spin（0 = Normal） |
| 2 | shoot_ctrl |
| 3 | reload_ctrl |
| 4 | autoaim_ctrl |
| 5 | supercap_ctrl |
| 6–10 | custom1–custom5 |

**新鲜度**：`age_us = (now_us − sample_tick_us) mod 2^32`。遥控帧率约 70–100 Hz，1 ms PDO 会连续多拍携带同一 `source_seq`，属正常；`source_seq` 不变且 `age_us` 持续增大时按失联处理。

### 2.3 ImuFeedback（偏移 72，56 B）

| 偏移 | 字段 | 类型 | 语义 |
| ---: | --- | --- | --- |
| 72 | source_seq | u32 | IMU 姿态消息帧序号，每解算一帧自增 |
| 76 | sample_tick_us | u32 | 该帧的采样时刻（MCU 本地 µs） |
| 80 | quaternion[0..3] | f32 ×4 | w, x, y, z |
| 96 | gyro[0..2] | f32 ×3 | rad/s |
| 108 | accel[0..2] | f32 ×3 | m/s² |
| 120 | temperature | f32 | ℃ |
| 124 | flags | u16 | bit0：已产生过姿态（`source_seq != 0`）；其余保留为 0 |
| 126 | reserved | u8[2] | 全零 |

从站已在下位机完成静态零偏与安装轴处理，主站**不要重复**做这两件事。

### 2.4 电机反馈区（偏移 128，128 B，预留）

8 槽 × 16 B，本版全零。主站必须按"无数据"处理：`age_ms` 视为 65535、在线位为 0。

## 3. RxPDO：主站 → 从站（256 B）

| 偏移 | 内容 | 字节 | 本版 |
| ---: | --- | ---: | --- |
| 0 | CommandHeader | 48 | 解析 |
| 48 | 电机命令区（预留） | 128 | 忽略，写零 |
| 176 | DeviceOperation（预留） | 32 | 忽略，写零 |
| 208 | DiagnosticRequest | 16 | 暂未处理 |
| 224 | reserved | 32 | 必须全零 |

### 3.1 CommandHeader（偏移 0，48 B）

| 偏移 | 字段 | 类型 | 主站要求 |
| ---: | --- | --- | --- |
| 0 | magic | u32 | 必须 `0x31434D43`（ASCII "CMC1"） |
| 4 | proto_major | u16 | 1 |
| 6 | proto_minor | u16 | 0 |
| 8 | byte_length | u16 | 必须 256 |
| 10 | slot_map_version | u16 | 必须 1 |
| 12 | host_session | u16 | 主机会话号；同一会话生命周期内保持不变 |
| 14 | reserved0 | u16 | 0 |
| 16 | command_seq | u32 | 只有产生新决策时才自增；重复发送同一命令不得自增 |
| 20 | mcu_boot_id_echo | u32 | 必须回显最近一次从 TxPDO 读到的 `mcu_boot_id` |
| 24 | feedback_seq_echo | u32 | 本命令依据的 `feedback_seq` |
| 28 | lease_us | u32 | 租约上限（µs），从站侧再夹一层 |
| 32 | compute_time_us | u32 | 主站控制计算耗时，诊断用 |
| 36 | flags | u16 | bit0 请求 arm；bit1 请求 disarm |
| 38 | enable_mask | u16 | 本版忽略 |
| 40 | reserved | u8[8] | 全零 |

### 3.2 从站校验规则（当前实现）

1. 只有新帧才处理：`SM2` 收帧计数变化视为新命令；重复读同一帧不刷新时间戳。
2. 整帧拒绝条件（任一不满足）：
   - `magic != 0x31434D43`
   - `byte_length != 256`
   - `slot_map_version != 1`
   - `mcu_boot_id_echo != 从站当前 mcu_boot_id`
   - 从站不在 OP 状态
3. 通过后：`accepted_host_session = host_session`，记录 `command_seq` 与接收时刻。
4. 掉 OP 或超过 100 ms 无新帧：`accepted_host_session = 0`，`status_flags.bit0` 清零。
5. **本版 RxPDO 不驱动任何外设**；电机命令、DeviceOperation、DiagnosticRequest 均不执行。

### 3.3 推荐主站时序

1. 进入 OP，读取 TxPDO，校验 `magic`/`proto_major`，记录 `mcu_boot_id`。
2. 选择 `host_session`（非 0，建议随机或递增）。
3. 每个周期填满 256 B：头 + 预留区全零；`command_seq` 仅在新决策时 +1；`mcu_boot_id_echo` 每周期回显。
4. 观察 TxPDO 的 `accepted_host_session == host_session` 与 `status_flags.bit0` 确认为已接纳。
5. 退出/崩溃前不做特殊清理；从站靠 100 ms 心跳/停更自行清除会话。

## 4. 通用规则

- **时间**：所有 `*_tick_us`/`mcu_tick_us` 都是 32 位 µs 计数，约 71.6 分钟回绕；**比较一律用模差** `(a - b)`，不要直接比大小。
- **序号**：`feedback_seq`、`source_seq`、`command_seq` 都是 32 位回绕计数，只用于判断"是否更新"，不做绝对比较。
- **预留区**：主站必须写零、不得依赖；从站不解析。
- **版本升级**：任何字段增删或偏移变化都要提升 `proto_major` 或 `slot_map_version`，不允许长度不变时悄悄换布局。

## 5. 主站侧结构体参考（C/C++）

```c
#pragma pack(push, 1)

typedef struct { uint32_t magic; uint16_t proto_major, proto_minor; uint32_t mcu_boot_id;
    uint32_t feedback_seq, mcu_tick_us, applied_command_seq; uint16_t accepted_host_session, operation_ack_seq;
    uint16_t status_flags, fault_code; uint8_t armed_mask, can_health, reserved[6]; } feedback_header_t;

typedef struct { uint32_t source_seq, sample_tick_us; float axis[4]; uint16_t controls;
    uint8_t protocol, status, reserved[4]; } remote_feedback_t;

typedef struct { uint32_t source_seq, sample_tick_us; float quaternion[4], gyro[3], accel[3];
    float temperature; uint16_t flags; uint8_t reserved[2]; } imu_feedback_t;

typedef struct { feedback_header_t header; remote_feedback_t remote; imu_feedback_t imu;
    uint8_t motor_feedback[128]; } tx_pdo_t;

typedef struct { uint32_t magic; uint16_t proto_major, proto_minor, byte_length, slot_map_version,
    host_session, reserved0; uint32_t command_seq, mcu_boot_id_echo, feedback_seq_echo, lease_us,
    compute_time_us; uint16_t flags, enable_mask; uint8_t reserved[8]; } command_header_t;

typedef struct { command_header_t header; uint8_t motor_command[128], device_operation[32];
    uint32_t diagnostic[4]; uint8_t reserved[32]; } rx_pdo_t;

#pragma pack(pop)

_Static_assert(sizeof(tx_pdo_t) == 256, "tx pdo");
_Static_assert(sizeof(rx_pdo_t) == 256, "rx pdo");
_Static_assert(sizeof(feedback_header_t) == 40, "header");
_Static_assert(sizeof(remote_feedback_t) == 32, "remote");
_Static_assert(sizeof(imu_feedback_t) == 56, "imu");
_Static_assert(sizeof(command_header_t) == 48, "cmd header");
```
